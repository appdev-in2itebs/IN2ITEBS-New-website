# In2IT EBS Realistic Object Heroes v7

This package contains 33 page-specific hero illustrations for the primary In2IT EBS website routes.

## Visual system

- Premium realistic CGI product-visualization style
- Front three-quarter tabletop composition
- Navy, cobalt, teal, white and graphite palette with restrained warm accents
- Matte polymer, anodized metal, coated paper and satin materials
- Genuine transparent PNG canvas with soft contact shadows
- No embedded copy, logos, brands, watermarks or readable UI
- Designed primarily for the right side of wide hero layouts

## Production notes

- Source dimensions: 1536 x 1024 px
- Format: PNG with alpha transparency
- Recommended display width: 560-760 CSS px on desktop
- Recommended object-fit: contain
- Keep the transparent breathing room; avoid tightly cropping the object tableau
- Provide route-specific alt text in the website rather than baking text into the artwork

`manifest.csv` maps every image to its intended page and visual concept. `PROMPTS.md` records the shared art direction and page-specific prompt set.

Generated with OpenAI image generation in reference-image mode, using the approved SAP Analytics Cloud pilot as the visual anchor.
